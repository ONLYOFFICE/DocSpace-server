# Tasks

The code of groups 1-8 is on `feature/personal-plugins`, the fourth review round included. One rule for every
task: it is ticked once each test it names has run green, on the `integration-test` stand or as a unit test, and
it asks for no case that is not written yet. A part the stand or a unit test cannot reach is named CODE-ONLY with
its reason and does not hold the tick back; a task that is CODE-ONLY as a whole is ticked once its reason is
written. The `Webplugins` suite ran green on the stand on 2026-11-26 after the fixes of group 8 (138 tests, the
two `Category=Bug` tests of P2 and P8 left out).
