# Data quality checklist

- Empty cells in required columns
- Duplicate rows or duplicate identifiers
- Numbers stored as text; mixed decimal separators
- Dates in more than one format or outside the expected range
- Inconsistent category names (case, spaces, spelling)
- Negative or zero values where they are impossible
- Mixed units or currencies in one column
- Totals or subtotals mixed in with the data rows
- Merged cells and multi-row headers
