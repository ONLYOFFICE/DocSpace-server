# Proofread

## Steps
1. Read the whole text to learn its purpose and audience.
2. Correct spelling, grammar and punctuation.
3. Apply the editorial style guide: capitalisation, numbers, dates, lists, terminology.
4. Check consistency: the same term, spelling variant and tense throughout.

## Output
The corrected text, then a change list with the columns Original, Corrected, Reason. Group repeated corrections into one entry with a count.

## Rules
- Do not rewrite a sentence that is correct.
- Keep the spelling variant (British or American) the document already uses.
