# Deck review

## Steps
1. Write the deck's storyline from its slide titles alone; if it does not read as a story, that is the first finding.
2. Score the deck on each review criterion from 1 to 5.
3. Go through the slides and note issues against the design checklist.

## Output
Scores per criterion, then up to ten issues as Slide, Issue, Fix, ordered by impact, then rewritten titles for the slides that need them.

## Rules
- Every issue comes with a concrete fix.
- Praise is limited to one line on what to keep.
