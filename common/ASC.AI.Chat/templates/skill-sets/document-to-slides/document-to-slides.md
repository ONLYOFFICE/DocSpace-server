# Document to slides

## Steps
1. Get the key messages (run the key-messages skill first when they are not given).
2. Order them into a story using the summary deck template.
3. For each slide choose a visual with the visual selection guide.
4. Write a closing slide with the decisions needed.

## Output
A slide list with Title, Points, Visual and Source reference; no more slides than the user asked for, eight by default.

## Rules
- One message per slide.
- Text taken from the source is shortened, not reworded into a different claim.
