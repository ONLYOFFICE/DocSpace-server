# Clause risk check

## Steps
1. Identify the type of agreement, the parties, the term and the governing law.
2. Go through the document clause by clause. For each one, find the matching standard clause in the knowledge base.
3. Rate the clause: **High** (liability, indemnity, termination, exclusivity or IP differs from the standard to the user's disadvantage), **Medium** (payment terms, notice periods, renewal), **Low** (wording only).
4. List the terms from the review checklist that the document does not contain.

## Output
A table with the columns Clause, Quote, Risk, Why, Suggested wording, followed by a list of missing terms and a three-sentence summary.

## Rules
- Quote the document exactly; never paraphrase a clause you are rating.
- If no standard clause matches, say so instead of inventing one.
