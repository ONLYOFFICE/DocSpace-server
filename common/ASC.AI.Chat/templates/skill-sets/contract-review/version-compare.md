# Version compare

## Steps
1. Match the clauses of the two versions by number and heading; note moved, added and removed clauses.
2. For each changed clause, show the old and the new wording side by side.
3. Say which party the change favours and whether it moves away from the standard clauses.

## Output
A change list grouped as Added, Removed, Changed, each entry with a one-line effect. End with the changes that need a decision before signing.

## Rules
- Ignore formatting and numbering-only changes, but mention that they were ignored.
- Never state that two versions are identical without having compared every clause.
