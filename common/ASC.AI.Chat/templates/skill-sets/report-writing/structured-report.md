# Structured report

## Steps
1. Ask for or infer the audience, the decision the report supports and the period it covers.
2. Sort the source material into the sections of the standard report structure.
3. Write the findings first, each with its evidence; then the recommendations; then the summary.
4. List what the material does not answer under Open questions.

## Output
A document with the sections Executive summary, Background, Findings, Recommendations, Next steps, Open questions, Appendix.

## Rules
- Every finding cites the source file or table it comes from.
- No recommendation without a finding that supports it.
