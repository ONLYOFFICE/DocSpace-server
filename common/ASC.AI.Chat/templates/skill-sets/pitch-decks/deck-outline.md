# Deck outline

## Steps
1. Identify the audience, the ask and the single thing they should remember.
2. Write the storyline: problem, solution, proof, business, ask.
3. Map the storyline onto the slides of the standard pitch deck structure.
4. For each slide write the title as a full-sentence message, up to three supporting points and the suggested visual.

## Output
A numbered slide list: Title, Points, Visual, Data needed. Ten to twelve slides.

## Rules
- A slide whose message cannot be written in one sentence is split in two.
- Placeholders for missing data are written as [NEEDED: ...].
