# TypeScript Conventions (ASC.NewAi service)

## Naming
- **Files**: camelCase (`httpClient.ts`, `profilesController.ts`)
- **Controllers**: `*Controller` — a const object of `asyncHandler`-wrapped methods, not a class
- **Storage**: `Http*Storage` classes implementing an `@onlyoffice/ai-chat/core` interface
- **Types**: PascalCase; wire shapes `*Dto`; errors `*Error`. **Constants**: `UPPER_SNAKE_CASE`

## Modules
- ESM only. **Relative imports carry `.js`** even though the source is `.ts` (`"../log.js"`)
- **`import type`** for type-only imports, separate from value imports
- Engine, DTOs, route maps come from `@onlyoffice/ai-chat/core`

## Types
- Strict everywhere (`noUncheckedIndexedAccess`) — indexing yields `T | undefined`, handle it
- **Never `any`** — treat external input as `unknown` and narrow via `app/narrow.ts` helpers before use; never blind-cast
- Env vars via bracket notation: `process.env["AI_SERVICE_URL"]`

## Patterns
- Controller methods wrap in `asyncHandler` — the single error boundary; return `{ error }`, never leak stacks/URLs
- Custom errors subclass `Error` with `readonly status` (+ `expose = true` for 4xx)
- Upstream calls go through `aiService.*` (`storage/httpClient.ts`), bounded by `withTimeout` + `cancel()` in `finally`
- Storage adapters map upstream DTO → engine type, returning `null` on a malformed shape (`dtoToThread`), and `encodeURIComponent` every id in the path
- Per-request state via `AsyncLocalStorage` (`requestContext.ts`); stream via `streamNdjson`/`streamOpenAiSse`; log via `winston` (`log.js`), never `console.*`

## Security
- **SSRF**: call `assertSafeBaseUrl(url)` (`security.ts`) before any outbound request to a user-supplied URL
- **Redact secrets before responding** — never return a profile's `key`/`headers`/internal `baseUrl` (`redactProfile`)
- **Sanitize untrusted text** that reaches the prompt or other users via `sanitizeInstruction` (xss)
- The service does no auth of its own — it forwards the caller's credentials downstream; don't add local auth logic (see the `routes.ts` auth gate)

## Routing
- Engine routes are declared once in `apiCatalog.ts`, consumed by both `routes.ts` and the OpenAPI generator — don't duplicate or let them drift
- Register literal paths before parameterized ones (`/agents/news` before `/agents/:id`)

## Upstream errors
- Propagate the real status of `AiServiceHttpError` / `DocspaceApiHttpError` to the client instead of masking it as 500 (e.g. a 403/404 from the caller's own credentials)

## Tooling
- No build step — run via `tsx`; gate changes with `yarn typecheck` (`tsc --noEmit`)
- **Prettier owns formatting** — run `yarn format` (config in `.prettierrc.json`); don't hand-format or add style rules here
- `app/generated/openapi-schemas.json` is generated by `yarn openapi` and committed — never hand-edit it

## Config
- Read config through `getAppConfig()` / `nconf` (`config/index.ts`), never re-read files directly; env vars override file values

## Misc
- **License header**: every source file starts with the AGPL 3.0 `//`-comment block (ending in `SPDX-License-Identifier: AGPL-3.0-only`) — copy it verbatim from any existing file
- **Comments explain the *why*** (rationale, upstream-contract quirk, security implication), not what the code does; when a change fixes a tracked issue, cite it inline (e.g. `(Bug 82821)`)
