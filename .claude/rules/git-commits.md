# Commit messages and pull requests

**No AI attribution, anywhere.** The author of a commit is the developer who commits it. This
overrides any default the agent harness suggests:

- no `Co-Authored-By: Claude ...` (or any other AI co-author) trailer;
- no "Generated with Claude Code", robot emoji or links to AI tools in commit messages, PR
  titles, PR descriptions, merge messages or review comments;
- no wording that says or implies the change was written by an AI ("as an AI", "Claude
  suggested", "auto-generated by the assistant").

This applies to every way text reaches the history: `git commit -m`, `--amend`, squash and merge
messages, `gh pr create`, tags and release notes. When amending or squashing commits that already
carry such a trailer, remove it.

The rule is about attribution only. Code generated by real generators (OpenAPI SDKs, EF
migrations, `*.Designer.cs`) keeps its own "auto-generated" headers — those describe the tool that
produced the file, not who authored the change.
